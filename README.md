### Live Projects

### [Helm](https://helmcv.app)
An AI-powered CV tailoring app. A three-stage pipeline parses the CV, scores it against a target job, and rewrites the bullets to match. Built on Next.js and FastAPI with PostgreSQL and S3, running on Kubernetes on AWS. GDPR and DPA compliant for UK and EU users.

### [LGR Lap Time Simulator](https://lgr-simulator.fly.dev/)
A quasi-static full-track lap time simulator built for Leeds Gryphon Racing. The model uses Pacejka tyres and tracks longitudinal and lateral load transfer through the corner. Source code at [LGRSimulations/LGR_FullTrackQSLapTimeSim](https://github.com/LGRSimulations/LGR_FullTrackQSLapTimeSim).
